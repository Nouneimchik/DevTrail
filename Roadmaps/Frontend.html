HTML

Огляд

HTML (Hypertext Markup Language) – це стандартна мова розмітки, яка використовується для створення структури та контенту веб-сторінок. Він становить основу кожної веб-сторінки, яку ви бачите в Інтернеті. HTML використовує теги для визначення структури та елементів у документі, що дозволяє браузерам інтерпретувати та відображати вміст належним чином.

Концепції для початківців

Структура документа

HTML-документ структурується за допомогою HTML-тегів. Базова структура HTML-документа включає тег HTML, тег head і тег body.

<!DOCTYPE html>
<html lang="en">
<head>
<title>Document</title>
</head>
<body>
<!-- The content of the website is written inside the body tag  -->
</body>
</html>

Форми

HTML-форми дозволяють користувачам вводити дані та надсилати їх на сервер. Це часто можна побачити на сторінках входу/реєстрації або на сторінках контактів. Ви можете створювати форми за допомогою тега та різних елементів керування форми, таких як введення тексту, прапорці, перемикачі, розкривні списки вибору та кнопки. Дані з форм можна обробляти за допомогою серверних технологій, таких як PHP або JavaScript. <form>

Семантичний HTML

Семантичний HTML – це спосіб написання HTML, який наголошує на значенні контенту, а не на його поданні. Це досягається за рахунок використання HTML-тегів, які мають специфічні семантичні значення. <header><footer><nav><section><article><aside></aside>

Використовуючи ці теги, ви можете створити більш доступну та легко зрозумілу веб-сторінку, яка також краще оптимізована для пошукових систем. Крім того, використання семантичного HTML може полегшити підтримку та оновлення вашого коду, оскільки він є більш організованим і легшим для розуміння.

Загалом, використання семантичного HTML є важливою найкращою практикою для будь-якого веб-розробника, який хоче створювати доступні, добре організовані та легко підтримувані веб-сторінки та програми.

CSS

Огляд

CSS – це мова таблиць стилів та одна з основних технологій у веб-розробці. Він використовується для дизайну HTML-сторінок, таких як макети, шрифти, колір, анімація та різні інші стилі. Таким чином, без CSS ваш сайт буде виглядати як звичайний звичайний документ Word.

Концепції для початківців

Вбудований, внутрішній та зовнішній CSS

Існує три методи додавання стилів CSS на вашу HTML-сторінку. По-перше, вбудований стиль записується всередині тега HTML за допомогою атрибута style. Але це найменш рекомендований варіант, оскільки стилі є унікальними для цього конкретного елемента HTML. Другий варіант – це внутрішній CSS, де ви використовуєте тег всередині тега вашого HTML-документа. <style><head> 

<head>
<!-- Internal CSS example  -->
<style>
h1 {
color: gray;
}
</style>
<!-- Link an external CSS file in a HTML document -->
<link rel="stylesheet" href="styles.css" />
</head>
<body>
<!-- Inline CSS example -->
<h1 style="color: turquoise;">Heading Text</h1>
</body>

Для зовнішнього варіанту створюємо новий CSS-файл і пов'язуємо його з HTML-документом. Це найпоширеніший метод використання CSS, оскільки файл може бути пов'язаний з іншими документами, що робить стиль придатним для повторного використання.

Браузер надає перевагу вбудованим стилям, потім внутрішнім стилям і, нарешті, зовнішнім стилям. Це означає, що будь-який стиль, що використовується за допомогою вбудованого методу, має пріоритет над будь-якими іншими стилями.

Селектори

Щоб застосувати стиль, спочатку потрібно виділити елемент, якщо ви не використовуєте вбудований стиль. Існують різні способи використання селектора, і деякі з часто використовуваних - це селектор типів, селектор класів та селектор ідентифікаторів. Кожен селектор має свій власний метод визначення селектора, наприклад, селектор класу завжди починається з . , а id селектори починаються з . . #

/* Attribute selector */

Властивості використовуються для визначення візуальних характеристик виділених елементів, таких як встановлення розміру тексту або встановлення кольору тексту. У той час як значення використовуються для встановлення конкретних значень для вибраних властивостей. Як і в наведеному вище прикладі коду, встановлює колір будь-якого тексту в цьому класі на синій. font-size color color: blue;

Використовуйте MDNWebDocs, W3Schools або довідкові веб-сайти CSS, щоб посилатися на ім'я та значення властивостей. Не відчувайте тиску, щоб запам'ятати кожну властивість.

Flexbox і Grid Layout

Визначення макета на веб-сторінці стало набагато простішим із впровадженням нових властивостей макета в останні роки. Використання методів верстки допомагає розташувати елементи на сторінці та з легкістю створювати складні макети.

Існує два поширених прийоми планування; і. Ми можемо використовувати їх, використовуючи властивість. Flexbox обробляє макет сторінки в одному вимірі, тому елементи розміщуються або горизонтально, або вертикально. У той час як Grid призначений для двовимірних планувань. flex grid display

Функція стилізації макета у двох вимірах означає, що існує більше властивостей для визначення макета, ніж Flexbox. Це може бути непосильним завданням для новачка, тому початок з Flexbox може бути кращим.

Скористайтеся вкладкою макета в інспекторі браузера, яка візуалізує макет сторінки. Це може спростити процес проектування, особливо з компонуванням Grid.

Адаптивний веб-дизайн

Веб-сайт, який адаптується під різні пристрої та розміри екрану, вважається адаптивним веб-сайтом. CSS дозволяє розробникам створювати веб-сторінки, оптимізовані для різних пристроїв і розмірів екранів, використовуючи такі методи, як медіа-запити і гнучкі макети. Зі збільшенням кількості мобільних користувачів більшість веб-сайтів використовують підхід, орієнтований на мобільні пристрої.

Перш за все, додавання метатегу viewport всередину вашого тегу дуже важливо для дизайну адаптивного веб-сайту. <head> 

<meta name="viewport" content="width=device-width, initial-scale=1">

Він повідомляє браузеру, що ширина веб-сайту така ж, як ширина пристрою, і є рівнем масштабування, з яким завантажується веб-сторінка. width=device-widthinitial-scale=1

Щоб застосувати стилі в різних розмірах екрана, ми використовуємо правила та вказуємо ширину екрана. У підході, орієнтованому на мобільні пристрої, ми пишемо стилі для екранів мобільних пристроїв та інші загальні стилі, а потім використовуємо медіазапити, щоб застосувати стилі до екранів більших розмірів. @media

Інші методи включають використання відносних одиниць, таких як , , (ширина вікна перегляду) або (висота вікна перегляду) замість фіксованих пікселів (). Згадана раніше схема сітки або flexbox також дозволяє створювати гнучкі контейнери серед багатьох інших. % em vw vh px

Анімації

Окрім зміни макетів та кольорів, CSS можна використовувати для додавання анімації для створення більш візуально привабливих веб-сайтів. Найпростіший спосіб додати деякі невеликі ефекти - це властивість, яка обмежує, але може бути використана для створення плавних змін під час наведення курсору або сфокусованого стану. transition

Щоб використовувати її, нам потрібно надати деякі властивості, які потрібні, щоб визначити, до якої властивості (колір, фон, трансформація або все) слід застосувати перехід, скільки часу потрібно для завершення переходу, а також визначити, як перехід відбувається протягом вказаного проміжку часу. Наприклад, використання застосує перехід лише до кольору елемента, і для повної зміни кольору знадобиться 0,4 секунди. Починається перехід повільно і поступово збільшує швидкість. Дізнайтеся більше за допомогою посібника від CSSReference.io. transition transition-property transition-duration transition-timing-function transtion: color 0.4s ease-in ease-in 

/* Provide basic styling */
button{
width: 100px;
height: 60px;
background: rgb(49, 98, 172);
/* "all" applies to color, background and transform property  */
transition: all 0.4s ease-in;
color: white;
}
/* When the button is hovered change background and scale the size by 1.1*/
button:hover{
background: rgb(21, 103, 82);
transform: scale(1.1);
}
/* there's also an optional delay property */
div{
/* the transition will only start after the 1 sec has passed*/
transition: all 0.4s ease-in-out 1s;
}

Але, має дуже просте використання і вимагає бути в стані, як або . Тому для створення більш складних анімацій ми використовуємо правило. Використовуючи ключові кадри, ми можемо визначити значення в різні періоди тривалості анімації. Визначення ключових кадрів схоже на те, але замість надання ширини, це те, що може бути будь-яким, яким ви хочете його бачити. Ключкадрам може бути надано будь-яке значення між to або та коли між ними немає змін. transition :hover :active @keyframes @media animation-name 0% 100% from to

Щоб використовувати визначений ключовий кадр, ми використовуємо властивість у елементі, який ми хочемо, щоб анімація відбувалася, і використовуємо те саме для значення.
